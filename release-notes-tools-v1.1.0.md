## EN — What's new in v1.1.0

Versioned bundle of **our own files** (no upstream app binaries here):

- `incy-download.exe` — manifest-based installer fetcher, SHA256 verify
  (`incy-download get windows-x64 --out incy-setup.exe`)
- `incy-downloader_1.1.0_all.deb` — installs `/usr/bin/incy-download` (needs `python3`)
- `incy-configs-v1.1.0.zip` — **the new changes**: custom DNS presets
  (`default` / `Iran Shecan` / `DoH`) + Telegram SOCKS5 config + bilingual guides

Guides: [Custom DNS](https://github.com/reza-em/incy-plus/blob/main/docs/custom-dns.md) ·
[Telegram proxy](https://github.com/reza-em/incy-plus/blob/main/docs/telegram-proxy.md)
